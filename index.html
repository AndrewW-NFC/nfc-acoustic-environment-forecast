Notes

How scoring works

Each hour starts from a 5.0 baseline: usable, but acoustically compromised. Favorable conditions add points and unfavorable conditions subtract points. The result is clamped between 0.0 and 10.0 and rounded to the nearest 0.5 for display. The descriptor is derived only from the displayed rounded score, so the same score always receives the same descriptor.

Data sources and night windows
  • Weather data: 10 m wind is from Open-Meteo. Near-ground wind is estimated from the same profile. Visibility uses API data when available; otherwise, it is estimated from precipitation and cloud cover.
  • Night windows: Night windows use astronomical twilight from sunrise-sunset.org.
  • Historical export: The historical export uses Open-Meteo Historical Weather API data, which is available back to 1940 for many locations. The browser UI caps a single export at 366 evening dates.
  • “Could not check”: This means the lookup service failed, timed out, or returned incomplete data. It does not mean the site is quiet.
Local noise settings
  • Foliage: Foliage noise is set by the user. Use a higher setting when leafed-out trees are close to the recorder.
  • Insects: Insect noise is included as a local-site factor because some insect bands and pulses can overlap nocturnal flight-call frequencies and mask NFC structure on the spectrogram.
  • Human-made noise: Road and aircraft context is shown separately from the acoustic score because actual source strength varies by traffic volume, flight activity, pavement conditions, and other factors the tool cannot directly measure.
    • Road traffic: Estimated from nearby OpenStreetMap roads tagged motorway, trunk, or primary; approximate distance to the selected point; road class; wind direction; and that night’s calm, humid, stable conditions.
    • Aircraft: Estimated from nearby mapped or built-in major airports and mapped runway alignment. It does not use live or scheduled flight data.
