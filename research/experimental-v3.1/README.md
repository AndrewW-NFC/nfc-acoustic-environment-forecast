# Archived experimental propagation model — inactive

These files preserve the v3.1 model before the defensible-scope revision. They are NOT imported by the active app and are not endorsed recording-quality predictions.

`acoustics.js` contains fixed source-height/path assumptions, coarse-profile bending diagnostics, wind-height extrapolation and unvalidated planning categories. `acoustic-model.md` is the historical description of that experiment, not the current product specification.

Revisit with raw flight-altitude data and explicit research scope. Altitude alone is insufficient: horizontal range, weather along the path, source directionality/strength, microphone response and local noise also matter. Validate any directional or quality predictions against recordings before exposing them to recordists.
